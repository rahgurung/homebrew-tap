# rahgurung/homebrew-tap

Homebrew casks for my Mac apps.

```sh
brew install --cask rahgurung/tap/displaydeck
```

| Cask | App |
|---|---|
| `displaydeck` | [DisplayDeck](https://displaydeck.rahulgurung.com): brightness, contrast and volume for external monitors from the menu bar |

Casks are updated automatically by each app's release workflow.
